# Следующие проверки после v0.4b

1. Физические Android Chrome и iOS Safari: FPS максимального флота, длительный floating joystick, диагонали, отпускание, второй палец и возврат после background/OS gestures. Desktop: Alt-Tab и mouse release вне окна.
2. Естественное прохождение FAST/REFERENCE: 5/10 рабочих, общий ресурс и ящики, порт, склад; оценить частичные наложения носов/корм при круговой модели корпуса.
3. Плотный AFK флот у одного источника: сравнить длительный доход по полным regrow/restock циклам. В 600s fixture есть отрицательный throughput delta; цены/скорости для компенсации не менялись.
4. Старые partial/building/pending saves и тесные группы лодок: reload без reset, сохранение cargo/reservations, постепенное расхождение; полный склад сохраняет груз и возобновляет выгрузку после расхода металла.
5. Full34 FAST/REFERENCE: combat при плотном движении, pirates return/defender repair, металл/partial den, Golden physical cash и покупки после реальной остановки.

Техническая v0.4b выполнена, hardware playtest остаётся. [Навигация](NAVIGATION_V04B.md) · [Валидация](VALIDATION_V04B.md) · [Предыдущая экономика](BALANCE_V04A.md).

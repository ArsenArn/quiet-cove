# Развитие портфолио

Оригинальная рыбацкая бухта объединяет рыбную экономику и позднюю добычу металла. Защитник создаёт новый тип автоматизации: безопасность морских маршрутов, при этом рыболовные рабочие не становятся расходным материалом. Дальняя экспедиция может открыть будущий третий регион, но сейчас это только завершение главы.

Сильная техническая демонстрация — независимая от Phaser симуляция, воспроизводимые тесты двух конфигов, исключение двойного зачисления и общие ресурсы/таймеры/работники. Для портфолио нужны измеренные прохождения, график реальной выручки из событий, видео нормальной игры и собственный визуальный стиль. Не использовать графику, код, аудио или брендинг референса.

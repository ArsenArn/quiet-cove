## Сохранения и исходные файлы

State v2 поддерживает v1 партии в тех же profile-specific ключах. Сначала создаётся точный `_backup_before_v02`, затем допускается запись нового state. Cash, rewarded IDs, активный baseline, cargo/заказы не откатываются. Уже начисленные v1 продажи не создают новые монеты. Исторический mixed catch не реконструируется; новые counters разделены. Проверка миграции — gameplay-v02 и save isolation tests. Небезопасный/повреждённый save остаётся в хранилище; запись новой временной партии выключена.

Исходный код/конфиги/документы v0.1 сохранены для сравнения в игнорируемой `test-results/v01-backup/`. Это копия файлов проекта, а не замена резервной копии браузерной партии. Git diff недоступен: каталог не является Git-репозиторием. Все записи в текущей работе находятся под `fishing-game/`, внешний проект и публикация не затронуты.

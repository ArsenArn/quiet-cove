## HOW TO RUN A BALANCE PLAYTEST

1. Select FAST.
2. Start a fresh game (F2 → Reset).
3. Press F2.
4. Start Recording. If a previous recording exists, export and Clear it first.
5. Close F2.
6. Play naturally without debug grants or time acceleration.
7. Stop Recording.
8. Export JSON.
9. Send JSON for analysis.

Start/Clear не сбрасывают прогресс; Export работает и во время записи. New Game завершает старую запись, новую надо включить явно.

## Управление

- WASD / стрелки и floating joystick: удерживайте мышь или палец на воде и тяните; отпустите, чтобы остановиться. Обычный click/tap по воде не задаёт маршрут. Нажатие на покупку и кнопки навигации сохраняют маршрут вокруг островов. Рабочие уступают игроку; неподвижный игрок не сдвигается separation. Камера следует за игроком.
- Рядом с открытым ресурсом ловля автоматическая; истощённая порция разбрасывает 8 ящиков в FAST или 15 в REFERENCE (до 150 активных, срок 60 игровых секунд); готовые ящики подбираются отдельно. У каждой лодки своё кольцо ловли. Вторая территория включает пиратов, защитника и разбор металла.
- Для выгрузки подойдите к причалу (радиус 38). Каждый ящик рыбы оставляет отдельную монету своего номинала. Подойдите ближе (радиус 38): только сбор начисляет деньги. Неполученные монеты сохраняются без объединения и ограничения количества выплат.
- Категории покупок появляются по квестам и остаются открытыми. Для оплаты остановитесь внутри круга (радиус 48) на 0,25с. Учитываются фактическое перемещение и запрошенная скорость: удержание управления в заблокированную сторону не считается остановкой. Движение прекращает взносы; уход и reload сохраняют их. Click на объект ведёт к нему. До полной оплаты обеих валют таймер не запускается. Полная оплата при достаточном балансе занимает 1–3 игровых секунды. После оплаты и завершения стройки действует cooldown 5с; следующий уровень/лодка требуют выхода за радиус 58 и повторного входа с остановкой 0,25с. Оставаться внутри круга безопасно даже после cooldown.
- У стройки есть отдельная кнопка **SKIP**. Она открывает окно **Wait / Cancel → Skip Now**. При остатке **<60с** пропуск бесплатный; при **≥60с** нужно подтвердить fake rewarded. Просто приблизиться или нажать круг недостаточно для пропуска.
- Вся зелёная **✓ TASK COMPLETE!** карточка получает награду одним нажатием. Пока награда не забрана, следующий квест не активируется. Затем камера показывает его цель со стрелкой и кругом и возвращается. Лодка остаётся управляемой, симуляция и оплата продолжаются. Keyboard/joystick/navigation сохраняют полный цикл подсказки; затем камера возвращается к текущей позиции игрока. Hint не телепортирует лодку. Квест победы над пиратами показывает логово.
- Golden Boat открывается **только по тапу на корабль или его подпись**. Над ним меняются TAP! и сумма каждые 3с. В popup можно отпустить катер или запустить fake rewarded. Сумма фиксируется; подтверждение создаёт ровно 10 кучек возле лодки. Их надо собрать. Физически собранные кучки увеличивают wallet и квесты «Заработать монеты», сохраняя отдельную статистику продажи рыбы. Quest rewards и debug grants не идут в earn_coins.
- «Объекты» открывает необязательный справочник. F2 открывает Balance Lab: профили, скорость, гранты, открытие зон, квесты, числовые настройки, подробные ресурсы/visibility и экспорт событий/конфига. Настоящей рекламы нет.

## Сохранения

Ключи `quiet_cove_fast_v1` / `quiet_cove_reference_v1` сохранены, внутри **state.version=3**. Профили изолированы. Сброс старой партии не нужен. Перед загрузкой v1/v2 создаётся точный `<ключ>_backup_before_v03`; для v1 также сохраняется прежний v02 backup. Кошелёк, груз, награды, baseline, completed_unclaimed, partial orders и старые неполученные деньги сохраняются. Старые объединённые стопки остаются одной выплатой с исходным значением: состав доставок достоверно восстановить нельзя. Уже начисленные деньги не создаются повторно.

Золотые кучки и ID транзакции сохраняются. v0.3.1 добавляет совместимые поля purchaseGuards, crate.expiresAt и отдельные счётчики дохода, сохраняя version=3 и прежние profile keys. До первой миграции сохраняется точный backup_before_v031. Исторический golden уже в активном квесте не начисляется повторно; pending кучки считаются при сборе. Старый дробный paid tail возвращается в ту же валюту перед переходом на целые взносы. Незавершённый fake ad после reload не подтверждается автоматически: предложение можно повторить до обычного истечения срока. Камера, input locks, движение к покупке и накопленная задержка остановки — временные состояния, в save не входят. После reload требуется новая остановка.

Автосохранение раз в 5с, при скрытии/pagehide и сразу после важных UI claims. Ошибка или повреждение save сохраняет исходные данные и запрещает перезапись временной новой партией; явный reset доступен только с подтверждением. Offline продолжаются только таймеры, без добычи, денег и боя.
